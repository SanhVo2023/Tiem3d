# Hướng Dẫn Chuẩn Bị File Để In 3D

Để sản phẩm in 3D đạt chất lượng tốt nhất, việc chuẩn bị file đúng cách rất quan trọng. Bài viết này sẽ hướng dẫn bạn từ A-Z.

## Các Định Dạng File Được Chấp Nhận

### Định dạng phổ biến:
- **STL**: Phổ biến nhất, hỗ trợ bởi mọi phần mềm
- **OBJ**: Có thể giữ màu sắc, texture
- **3MF**: Định dạng mới, giữ nhiều thông tin hơn STL

### Định dạng CAD:
- **STEP/STP**: File kỹ thuật, độ chính xác cao
- **F3D**: File Fusion 360
- **BLEND**: File Blender

## Checklist Trước Khi Gửi File

1. **Kiểm tra Watertight (kín nước)**
   - Mesh phải kín hoàn toàn
   - Không có lỗ hổng hoặc mặt bị thiếu

2. **Kiểm tra Normal**
   - Tất cả normal phải hướng ra ngoài
   - Flip normal nếu cần

3. **Đơn vị đo lường**
   - Xác nhận đơn vị: mm, cm, hoặc inch
   - Ghi rõ kích thước mong muốn

4. **Độ dày tường**
   - FDM: Tối thiểu 1.2mm
   - Resin: Tối thiểu 0.8mm

## Phần Mềm Thiết Kế Miễn Phí

| Phần mềm | Độ khó | Phù hợp cho |
|----------|--------|-------------|
| Tinkercad | Dễ | Người mới bắt đầu |
| Blender | Trung bình | Mô hình nghệ thuật |
| Fusion 360 | Khó | Thiết kế kỹ thuật |
| FreeCAD | Trung bình | CAD miễn phí |
