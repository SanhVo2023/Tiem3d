# CLAUDE.md

## Project and architecture

Tiệm 3D is a Vietnamese printing and design website. Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4. Netlify serves the static export in `out/`.

Preserve `output: "export"` and `trailingSlash: true`. No runtime API routes, server actions or runtime image optimization. Dynamic routes need `generateStaticParams()`. Preserve real 404 responses; never add a catch-all homepage rewrite.

Keep `agentRules: false` in Next config so the framework does not modify the existing `AGENTS.md`.

## Commands and verification

Use Node 22.14 or newer.

```sh
npm ci
npm run dev
npm test
npm run lint
npm run typecheck
npm run assets:check
npm run build
npm run audit:export
npm audit
npm run preview
```

The tests cover quote validation and message construction. The export audit checks HTML, links, metadata, images, FAQ/schema consistency and the sitemap. Browser verification is still required for layout, focus, navigation, forms and accessibility. Do not claim a check passed without its actual result.

`npm run preview` and `npm start` serve the static output. They do not run a Next.js server. Stop a development server on port 3000 before previewing on that port.

The homepage is rendered on the server with a shared Header/Footer. The specimen picker has client state. All service routes use `src/components/services/ServicePage.tsx`. Critical content must be visible before hydration.

## Customer facts

Tân Phú receives no customer visits. Every order uses a third-party courier. Keep `customerVisits: false`; do not add directions inviting visits, estimated coordinates or LocalBusiness markup. It is currently ineligible for a Google Business Profile. The exact current ward is unconfirmed; address helpers use the familiar Tân Phú area.

For Thủ Đức, retain the instruction to contact the shop before visiting. Do not infer a change in its operations from facts supplied only about Tân Phú.

The quote page prepares a message on the customer's device. A phone number is optional. The customer copies the preview and opens Zalo through separate actions, then sends the message and attaches files there. Do not simulate uploads, automatic submissions or successful clipboard writes.

Generated portfolio images and scenarios are illustrations. Keep that disclosure visible. Real project claims, reviews, opening arrangements and performance guarantees need evidence from the owner.

## Content and SEO

MDX lives in `content/blog/`. The route renders the H1; start article sections at `##`. Keep dates accurate. Rendered FAQs and JSON-LD must use identical content.

Use the shared MDX components for prices and contact information. The article template adds `ThongTinLienHe`; do not duplicate it. Keep related-post tags specific. Single-post tag pages are noindex and stay out of the sitemap.

Use explicit canonical URLs with trailing slashes. Open Graph and Twitter data must describe the current page. Prefer existing JPEG social cards; the export audit verifies that every target exists. New cards are generated by `npm run assets:social`.

No unverified aggregate ratings, invented publication dates, business coordinates or duplicate location pages. See `docs/google-business-tan-phu.md` for official eligibility and visibility guidance.

## Styling and assets

Use sentence-case Be Vietnam Pro headings, Open Sans body text and monospace for measurements. Orange is the accent; darker rust is used for readable text on light backgrounds. Keep keyboard focus visible and honor reduced motion. Use native scrolling.

Use `src/components/ui/Img.tsx` for CDN-aware images, with useful alt text and dimensions or a stable aspect-ratio container. Preload only the primary image. Check mobile cropping and captions.

`NEXT_PUBLIC_CDN_URL` rewrites only `/assets/*`; upload those files before enabling it. Fonts, CSS and JavaScript stay on the origin. Never use `assetPrefix` for this asset-only CDN.

## Configuration and release

Credentials belong in ignored `.env.local`; `.env.local.example` documents optional settings. Do not print or commit secrets. Image generation is manual, never part of the production build.

Netlify uses Node 22, builds with `npm run build`, and publishes `out/`. Review `README.md` and `docs/production-audit.md` for release checks and actual validation results.
